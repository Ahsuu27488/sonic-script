## Scope

In: hotkey (tap-toggle + hold, Enter / Esc while recording) → record → voice gate → Opus → Groq → normalizer →
paste; console window + log file; key from the environment (`GROQ_API_KEY`, same as `eval/`); the model catalog
`spec/models.json` generated by `eval` (D-017).

Out (M2): tray, settings window with the model catalog, HUD / Voice Ring, pop-up mic on text fields (D-016),
Credential Manager, history UI, Gemini engine, preferred + fallback model with the learned deadline (D-017),
installer, autostart. M1 still logs per-request timings in the shape the learned deadline will read. Out (later): focus pill, streaming, Silero VAD (only if the energy gate fails).

## Approach

0. **Toolchain (owner, once, needs one UAC click):**
   `winget install Rustlang.Rustup` and
   `winget install Microsoft.VisualStudio.2022.BuildTools --override "--quiet --wait --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"`.
   The C++ build tools are needed for the MSVC linker and to compile libopus.
1. **Normalizer first (core, no Windows code).** Rules as data in `spec/normalizer/rules.json`; `cases.json`
   built from the real M0 failures:
   - Script guard: Urdu (U+0600-06FF) and Devanagari (U+0900-097F) letters → transliterate with a small
     letter table; if more than 30% of letters are non-Latin, mark the output "needs LLM" (M1: re-ask once with
     `groq-whisper-hint+gptoss20b`'s LLM step).
   - Word list (D-014): fuzzy-match the user's words (edit distance on lowercase, word-boundary, length ≥ 3):
     "Jaminai" → "Gemini", "Codec" → "Codex". `words.txt` next to the exe in M1.
   - Phantom filter: drop output that is only a phrase from the Whisper hint ("main abhi meeting mein hoon")
     or a known Whisper phantom ("Thank you for watching", "Tch, tch").
   - Spacing and a trailing space so the next dictation does not glue on.
2. **Voice gate (D-007).** Port `trim_silence`; a clip with < 300 ms of speech is never sent. Tested on the
   two M0 silence clips (must give no request) and all 42 speech clips (must pass).
3. **Encode + Groq.** Ogg/Opus 16 kbps (`audiopus` static build + `ogg`); fallback FLAC if the libopus build
   fights us. reqwest + rustls, one client, connection opened when the key goes **down** (warm by release),
   10 s timeout, one retry on 5xx/429. Model id and hint from `spec/`, never hard-coded.
4. **Golden check (no mic needed).** `sonicscript.exe --file <wav>` and `--bench <dir>` run the real pipeline
   on `spec/fixtures/audio/`; accuracy must match `groq-whisper-hint` in M0 (±2 points) or better, and
   Latin-only output must go from 93% to ≥ 99% (blueprint §2.2).
5. **Hotkey + audio (D-015).** Low-level hook on Right Ctrl. Key down → open the mic + warm connection right
   away (so a hold loses nothing). Up within 300 ms with no other key → **toggle** mode: keep recording until
   the next Right Ctrl tap or Enter, then transcribe and paste; Esc cancels. Held > 400 ms → **push-to-talk**,
   stop on release. Any other key while Right Ctrl is down → cancel (Right Ctrl + C stays a shortcut). Only
   Enter and Esc are swallowed, and only while recording; nothing else is ever swallowed. The hook callback
   only posts a message (Windows unhooks slow hooks). A console beep / title change shows recording state
   until the HUD exists (M2). Safety cap: stop at 5 minutes.
6. **Changeable key (D-018).** The key is a setting, never hard-coded. M1: `hotkey = "RightCtrl"` in
   `config.toml`, plus `sonicscript.exe --set-key` ("press the key you want", saves it). Allowed: modifier keys
   on one side (Right/Left Ctrl, Alt, Shift, Right Win), F13-F24, F1-F12, Pause, Scroll Lock, Caps Lock, Insert,
   and mouse side buttons (XButton1/2). Refused with a reason: letters, digits, Space, Enter, Esc, Tab,
   Backspace, arrows (they type or edit text, or are the stop/cancel keys). Left Alt and Caps Lock get a
   warning (menus / caps state). The tap / hold / cancel rules work the same for every key. M2 shows the
   same "press a key" box in the settings page.
7. **Inject.** Save clipboard → set text (plus `ExcludeClipboardContentFromMonitorProcessing` so Win+V history
   stays clean) → `SendInput` Ctrl+V (Ctrl+Shift+V when the foreground class is a terminal:
   `CASCADIA_HOSTING_WINDOW_CLASS`, `ConsoleWindowClass`) → restore clipboard after 300 ms. Elevated window
   (UIPI) → console message "copied, press Ctrl+V", text left on the clipboard.
8. **Model catalog (D-017).** `python -m sonic_eval catalog` writes `spec/models.json` from the M0 runs:
   per engine accuracy, English kept, % Roman, p50 / p95, failure rate, cost per 1,000, free-tier limits,
   test date, and `recommended: true` for the D-011 default. Tested offline with fake rows.
9. **Latency log.** `%LOCALAPPDATA%\SonicScript\log.jsonl`: timestamp, clip length, stage timings, bytes,
   engine, error. **No audio and no text** (personal data); text only with `--log-text`.
10. Delegate boilerplate (CI job, cpal capture, clipboard helpers) to Gemini CLI through Foreman; the hook,
   normalizer rules and review stay with Claude.

## Risks

| Risk | Mitigation |
|---|---|
| Antivirus flags an unsigned exe with a keyboard hook | Local build only in M1; signing (SignPath) before M4. |
| Hook breaks Right Ctrl shortcuts | Swallow only Enter / Esc while recording; cancel on any other key; manual matrix row. |
| Toggle mode left on by accident (mic stays open) | Recording state visible (console now, HUD in M2); 5-minute cap; voice gate drops silent clips. |
| Clipboard restore races the paste | 300 ms delay, restore only if the clipboard still holds our text. |
| libopus does not build on Windows | FLAC fallback (pure Rust), ~4x bigger than Opus but ~2x smaller than WAV. |
| Groq free-tier limits (2,000 requests/day) | Far above personal use; 429 shows a clear message. |

## Rollback

Nothing is installed or live: stop the exe (Ctrl+C in its console) and the hook is gone. Revert = delete
`desktop/` and `spec/normalizer/` on the branch. The eval tool is untouched.

## Assumptions

- The owner's mic works through WASAPI shared mode at 48 kHz and we resample to 16 kHz (as `eval` records).
- `groq-whisper-hint` stays the default (D-011); the LLM step is used only when the script guard gives up.
- Right Ctrl is free on the owner's keyboard layout (D-015).
