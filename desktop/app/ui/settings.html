Settings

The settings window comes in the next update. Until then, SonicScript uses the settings file and a few commands.

Settings file
%APPDATA%\SonicScript\config.toml
Restart SonicScript after editing it.
Dictation key
sonicscript --set-key, then press the key you want.
API keys
sonicscript --key gemini (and groq) saves a key in Windows Credential Manager.
Your words
sonicscript --words opens your word list.
